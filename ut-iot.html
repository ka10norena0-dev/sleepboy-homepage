告知の通り、本ドキュメントに関するサポート・設定に関する ご質問は受け付けておりません。本機能は上級者向けです。 設定内容にご了承いただける方のみご利用ください。

■ 目的及び接続機器設定

SwitchBot ハブミニで赤外線シーリングライトを消灯する場合
あらかじめ赤外線リモコンでライトのOFFを記憶させておく。
動作の名前は何でもよい。

■ 設定方法

1. IFTTT (Webhooks)

IFTTTページにて以下のアプレットを作成。

  • IF: 「Receive a web request (Pro)」
  • Then: 「Turn off appliance with Hub Plus IR remote」(SwitchBot)

※現在、IFTTT側でWebhooks（Receive a web request）を利用するには、 有料プラン（IFTTT Pro等）の契約が必要です。

作成後、SwitchBotアプリ設定画面の「サードパーティーサービス」で IFTTTとのリンク（相互連携）を設定しておきます。

作成完了後、画面下部の「Your webhook URL」に表示されるURLを、 Sleep Boyの [1] IFTTT WEBHOOK URL に入力し、OKをクリック。

[test] をクリックし、対象の機器が消灯すれば成功です。

2. SwitchBot API

SwitchBotアプリで開発者オプションを有効にし、

  • トークン
  • クライアントシークレット

を取得して、それぞれSleep Boyの該当項目に入力。

その状態で [get devices] をタップすると、 自動的にデバイスIDが入力されます。

※複数存在する場合は一番上のIDが入るため、 対象が違う場合は該当するIDを手入力してください。

  • command: この事例（赤外線ライトOFF）の場合は turnOff を入力（※大文字小文字・スペースなしに注意）
  • commandType: 空白でOK（デフォルトの command になります）

OKをクリックして保存。

[test] をクリックし、対象が消灯してレスポンス （statusCode: 100）が出れば成功です。

■ 利用方法

[test] でエラーがなければ、設定されている情報に基づき、 タイマー切れまたは睡眠検知となった瞬間に、1および2のシステム （入力されているもの）をトリガーしにいきます。

[Reference] Sleep Boy ULTRA IoT Setup Example

⚠️ This document describes one example configuration for Sleep Boy's ULTRA (IoT) feature, provided for reference purposes only.

As previously announced, we do not provide support for questions related to this document or its setup. This feature is intended for advanced users only. Please use it only if you are comfortable with the configuration involved.

■ Purpose & Device Setup

Setting up SwitchBot Hub Mini to turn off an infrared ceiling light
Pre-record the "light OFF" command using the IR remote learning feature beforehand.
The action name can be anything you like.

■ Setup Instructions

1. IFTTT (Webhooks)

Create the following applet on the IFTTT website.

  • IF: "Receive a web request (Pro)"
  • Then: "Turn off appliance with Hub Plus IR remote" (SwitchBot)

* As of now, using Webhooks (Receive a web request) on IFTTT requires a paid plan (such as IFTTT Pro).

After creating the applet, go to the SwitchBot app's settings screen and link it with IFTTT under "Third-Party Services."

Once set up, copy the URL shown under "Your webhook URL" at the bottom of the page, and paste it into [1] IFTTT WEBHOOK URL in Sleep Boy, then tap OK.

Tap [test] — if the target device turns off, the setup was successful.

2. SwitchBot API

Enable Developer Options in the SwitchBot app, and obtain:

  • Token
  • Client Secret

Enter each value into the corresponding field in Sleep Boy.

With these entered, tap [get devices] — the Device ID will be filled in automatically.

* If multiple devices exist, the topmost ID will be used. If this isn't the correct device, enter the appropriate ID manually.

  • command: For this example (IR light OFF), enter turnOff (note: case-sensitive, no spaces)
  • commandType: Leave blank (defaults to "command")

Tap OK to save.

Tap [test] — if the target device turns off and the response returns statusCode: 100, the setup was successful.

■ How It Works

If [test] completes without errors, the configured systems (1 and 2, whichever are set) will automatically trigger the moment your timer expires or sleep is detected.
